# Student Performance Analysis — Task 1

Data Science/Analysis with Python Internship at Maincrafts Technology.

## Overview
This project explores the UCI **Student Performance** dataset (`student-mat.csv`) using Python.
It follows the standard data science workflow: **load → clean → analyze → visualize → conclude.**

## What's Included
- `student_analysis.ipynb` — Jupyter Notebook with full analysis
- `student-mat.csv` — dataset (395 students, Math course, UCI ML Repository)

## Steps Performed
- Loaded data with pandas and inspected shape, dtypes, and missing values
- Removed duplicates and cleaned the dataset
- Answered key questions:
  - Average final grade (G3)
  - Number of students scoring above 15
  - Correlation between study time and performance
  - Gender-wise performance comparison
- Visualized findings with a histogram, scatterplot, and bar chart

## Tools Used
Python, pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

## Dataset Source
Cortez, P. (2014). Student Performance. UCI Machine Learning Repository.
